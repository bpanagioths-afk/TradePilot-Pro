## Sprint 28 — MT5 Synchronization Engine v2

Completed backend work:

- Added canonical Trade Lifecycle documentation.
- Added `mt5_position_id` to identify one MT5 position across all related deals.
- Added modular MT5 synchronization package:
  - `models.py`
  - `builder.py`
  - `aggregator.py`
  - `validator.py`
  - `repository.py`
  - `sync_service.py`
- Added aggregation of entry, exit and partial-close deals into one Trade record.
- Added open-position support and transition to closed Trade state.
- Added safe reconciliation for recently closed positions when the general history query omits a closing deal.
- Added idempotent upsert behavior: repeated sync updates existing Trades instead of creating duplicates.
- Added validation errors to the sync response.
- Excluded open positions from historical Portfolio and Analytics calculations.
- Preserved the existing `/mt5/sync` endpoint through a compatibility wrapper.

Completed frontend work:

- Migrated Dashboard summary metrics to the shared Widget System.
- Corrected positive/negative status colors.
- Removed `Average: undefined` fallback behavior.
- Consolidated Dashboard, Portfolio and Analytics around the same Widget Design System.
- Confirmed Portfolio as the reference UI implementation.
