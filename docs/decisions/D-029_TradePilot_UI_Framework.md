# D-029 — Design System Before New Screens

**Status:** ACCEPTED

### Decision

Κάθε νέο μεγάλο frontend module πρέπει πρώτα να υιοθετεί το κοινό TradePilot Design System πριν προστεθούν εξειδικευμένα UI στοιχεία.

### Reason

Εξασφαλίζεται συνέπεια, επαναχρησιμοποίηση και επαγγελματική εικόνα σε όλο το προϊόν.
