# D-002

## MT5 Ticket as External Reference

Status: ACCEPTED

Decision

Το MT5 Ticket αποθηκεύεται αποκλειστικά στο πεδίο:

```text
mt5\\\_ticket
```

Δεν χρησιμοποιείται για εσωτερική ταυτοποίηση trade.

Reason

Το MT5 ticket ανήκει στο εξωτερικό σύστημα MT5.

Το TradePilot Pro πρέπει να έχει δικό του ανεξάρτητο database identity.
