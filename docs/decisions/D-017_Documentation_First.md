# D-017

## Documentation First

**Status**

ACCEPTED

### Decision

Κάθε σημαντική αρχιτεκτονική αλλαγή ενημερώνει άμεσα το Documentation Pack.

Ενημερώνονται όπου απαιτείται:

* CHANGELOG
* DECISIONS
* PROJECT MASTER
* PROJECT HISTORY
* BACKLOG
* README

### Reason

Η γνώση του project δεν πρέπει να εξαρτάται από μία συνομιλία.

Το documentation αποτελεί μέρος του ίδιου του προϊόντος.
