# D-033 — Documentation as a Deliverable

**Status:** ACCEPTED

### Decision

Η τεκμηρίωση θεωρείται επίσημο παραδοτέο κάθε Sprint και ενημερώνεται μαζί με τον κώδικα πριν θεωρηθεί ολοκληρωμένη η εργασία.

### Reason

Η γνώση του έργου πρέπει να παραμένει πλήρης, ανακτήσιμη και ανεξάρτητη από τις συνομιλίες.
