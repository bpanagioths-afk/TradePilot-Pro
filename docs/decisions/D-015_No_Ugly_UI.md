# D-015

## No Ugly UI

**Status**

ACCEPTED

### Decision

Κάθε νέο module του TradePilot Pro πρέπει να ακολουθεί κοινές αρχές επαγγελματικού UI.

Αυτό περιλαμβάνει:

* καθαρό layout
* συνεπή components
* σωστά margins και spacing
* επαναχρησιμοποιήσιμα στοιχεία
* επαγγελματικές κάρτες (cards)
* ξεκάθαρη ιεραρχία ενεργειών
* προβλέψιμη συμπεριφορά του interface

### Reason

Το UI αποτελεί μέρος του προϊόντος.

Η ποιότητα της εμπειρίας χρήσης επηρεάζει άμεσα την αξιοπιστία που αποπνέει η εφαρμογή.
