# D-032 — Local First, Cloud Ready

**Status:** ACCEPTED

### Decision

Η τρέχουσα έκδοση παραμένει local-first, αλλά κάθε νέα αρχιτεκτονική επιλογή πρέπει να επιτρέπει μελλοντικό cloud συγχρονισμό χωρίς εκτεταμένες αλλαγές.

### Reason

Διατηρείται η απλότητα σήμερα και η δυνατότητα επέκτασης αύριο.
