# D-012

## Safe Development

Status: ACCEPTED

Decision

Προτιμώνται μικρά ασφαλή βήματα.

Δεν γίνονται μεγάλα rewrites χωρίς σοβαρό λόγο.

Reason

Το TradePilot Pro έχει ήδη αρκετά modules.

Μεγάλα rewrites αυξάνουν τον κίνδυνο regression bugs.

Development Principle

```text
Small safe steps.
Stability before speed.
```
