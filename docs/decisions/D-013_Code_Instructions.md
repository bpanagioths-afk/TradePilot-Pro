## Exact Code Instructions

Status: ACCEPTED

Decision

Οι οδηγίες ανάπτυξης προς τον χρήστη δίνονται πάντα με καθαρό και ακριβή τρόπο:

* Βρες αυτό
* Βάλε ακριβώς από κάτω αυτό
* Αντικατάστησε μόνο αυτό το block

Reason

Ο χρήστης δουλεύει βήμα-βήμα και θέλει να αποφεύγονται λάθη σε αρχεία κώδικα.

Implementation Rule

Αποφεύγουμε ασαφείς οδηγίες όπως:

* άλλαξε κάπου αυτό
* βάλε το περίπου εδώ
* κάνε ένα γενικό refactor
