# D-006

## Multiple Trading Plans

Status: ACCEPTED

Decision

Ένας χρήστης μπορεί να έχει πολλά Trading Plans.

Examples

* Forex Conservative
* Gold Intraday
* FTMO Challenge
* The5ers Challenge
* Swing Trading

Reason

Διαφορετικές στρατηγικές χρειάζονται διαφορετικούς κανόνες.

Ένας trader δεν λειτουργεί πάντα με το ίδιο risk profile, market, session ή prop firm rule set.
