# D-007

## Rule Engine Philosophy

Status: ACCEPTED

Decision

Το Rule Engine αξιολογεί execution quality και όχι απλώς profit.

Reason

Ένα losing trade μπορεί να είναι σωστό αν ακολούθησε το Trading Plan.

Ένα winning trade μπορεί να είναι κακό αν παραβίασε κανόνες.

Product Principle

```text
Execution > Profit
```
