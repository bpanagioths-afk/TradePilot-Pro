# D-010

## Snackbar Notifications

Status: ACCEPTED

Decision

Δεν χρησιμοποιούμε:

```javascript
alert()
```

Χρησιμοποιούμε Snackbar notifications.

Reason

Το `alert()` διακόπτει τον χρήστη και δίνει ερασιτεχνική εμπειρία.

Το TradePilot Pro πρέπει να έχει professional UX.

Implementation Rule

Success, error, warning και info messages πρέπει να εμφανίζονται με Snackbar pattern.
